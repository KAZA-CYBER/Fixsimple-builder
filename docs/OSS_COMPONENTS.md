# OSS Components

Open-source projects are a parts bin and reference source, not the identity of
FixSimple Builder.

Potential areas for later evaluation:

- OpenHands: file/shell tool patterns
- Aider: repository mapping, edit formats, Git patterns
- mini-SWE-agent / SWE-agent: minimal engineering-loop patterns
- Cline: permission and Plan/Act UX concepts
- Ollama / llama.cpp / vLLM: local inference endpoints
- LiteLLM: optional model adapter

No component listed here is automatically approved as a dependency.

Any dependency must be evaluated before adoption for:
- license
- maintainability
- security
- portability
- coupling
- actual need
